# 애플 🩷

카카오톡 '나와의 메모'처럼, 나와의 대화창에 말을 걸 듯 남기는 채팅형 메모 앱입니다.
설치 없이 사파리에서 열고, 홈 화면에 추가하면 앱처럼 쓸 수 있어요.

- 앱 주소: **https://ktbn8ddgk9-cmd.github.io/nayeon-memo/**
- 서버·로그인 없음: 메모와 사진은 보는 기기의 브라우저(IndexedDB)에만 저장됩니다.

## 쓰는 법

1. 사파리에서 앱 주소를 엽니다.
2. 아래 공유 버튼 → **홈 화면에 추가** 를 누르면 아이콘이 생깁니다. (앱처럼 전체 화면으로 열려요)
3. 맨 아래 입력창에 메모를 쓰고 핑크색 ↑ 버튼을 누르면 대화 말풍선처럼 쌓입니다.
4. 말풍선의 `⋯` 를 누르거나 길게 누르면 **수정 · 복사 · 폴더 이동 · 삭제** 를 고를 수 있어요.

## 기능

| 기능 | 설명 |
| --- | --- |
| 채팅형 메모 | 하얀 바탕, 날짜 구분선, 작성 시각(오후 3:50), 연핑크 말풍선 |
| 사진 첨부 | 입력창 왼쪽 사진 버튼, 여러 장 첨부·자동 압축·전체 화면 확대 |
| 음성 입력 | 툴바 🎤 버튼으로 말하면 입력창에 글자로 들어감(Web Speech API). 지원되지 않는 화면에서는 안내 후 키보드 마이크를 쓰도록 토스트로 알려 줌 |
| 폴더 | 전체 메모 / ☕ 일상 / 🛍️ 쇼핑·위시 / ✅ 할 일 / 🧾 사진·영수증, 자유롭게 추가·이름 변경·삭제 |
| 제목·태그 | `✨ 제목·태그 붙여서 쓰기` 로 제목·태그 입력, 본문의 `#태그` 자동 인식 |
| 검색 | 돋보기로 내용·태그·날짜 검색, 태그 칩·폴더로 필터 |
| 캘린더 | 메모가 있는 날 핑크 점 표시, 날짜를 누르면 그날 메모 모아보기 |
| 백업 | 설정에서 전체 메모 JSON 내보내기 / 불러오기(추가 또는 전체 복원) |
| 잠금(선택) | 4~8자리 PIN으로 앱 잠금. PIN을 잊으면 열 수 없으니 백업 후 사용 |

## 파일 구성

```
index.html     화면 골격
styles.css     디자인(하양·핑크)
app.js         메모·폴더·사진·검색·캘린더·백업·잠금 로직
manifest.json  PWA 설정(홈 화면 추가)
sw.js          오프라인 캐시
icon.svg / icon-*.png  앱 아이콘(핑크 하트)
```

## 주의

- 데이터는 **기기별 브라우저 저장소**에 남습니다. 폰을 바꾸거나 사파리 데이터를 지우면 사라지므로,
  설정 → `📤 메모 내보내기` 로 백업 파일을 받아 두세요.
- 방문자 기록·광고·외부 전송이 없는 정적 페이지입니다.
